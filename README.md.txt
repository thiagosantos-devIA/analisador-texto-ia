# 🧠 Analisador de Texto com IA

Aplicação web desenvolvida em **Python + Streamlit** que analisa textos usando IA,
fornecendo análise geral, pontos positivos e sugestões de melhoria.

## 🚀 Funcionalidades
- Análise automática de textos
- Personalização por tema e público
- Interface simples e intuitiva
- Integração com OpenAI (API Key do usuário)

## 🖥️ Como usar
1. Acesse o app
2. Insira sua OpenAI API Key
3. Preencha o texto
4. Clique em **Analisar**

🔒 A chave **não é salva** e é usada apenas durante a sessão.

## 🛠️ Tecnologias
- Python
- Streamlit
- OpenAI API

## ▶️ Rodar localmente
```bash
pip install -r requirements.txt
streamlit run app.py
